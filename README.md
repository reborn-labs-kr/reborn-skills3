# 스킬팩3 — SNS 올인원

산 스킬팩3를 한 줄로 깝니다. **결제 후 받은 주문번호가 필요합니다.**

```
npx --yes reborn-skills3@latest <주문번호>
```

클로드 코드 안에서 하실 때는 **맨 앞에 `!` 를 붙이세요.**

```
!npx --yes reborn-skills3@latest <주문번호>
```

> `!` 는 클로드의 판단을 거치지 않고 그 줄을 그대로 실행합니다. 낯선 패키지에 정체불명
> 문자열을 붙여 돌리라고 하면 클로드가 거절하는 게 정상이고, 그 판단은 옳습니다.
> `--yes` 도 빼지 마세요 — 클로드 코드 안에서는 답할 사람이 없어 확인 질문에 걸려 조용히 멈춥니다.

**★다 깐 다음 클로드 코드를 껐다 켜셔야 적용됩니다.** 그다음 «이번 주 콘텐츠 짜줘» 라고 말해 보세요.

## 선택지

```
--with-optional   따로 돈이 드는 열쇠가 필요한 스킬까지 깝니다 (AI 이미지 등)
--check           깔지 않고 지금 상태만 봅니다
--no-rules        지금 폴더의 CLAUDE.md 에 «언제 펴라» 쪽지를 넣지 않습니다
--lang=en         쪽지를 영어로 넣습니다
```

## 이 설치기가 하는 일과 안 하는 일

- 남이 만든 스킬 파일을 **복사해 두지 않습니다.** 각 제작자의 공식 설치 명령(`npx skills add …`)을 대신 실행합니다.
  만든 곳과 라이선스는 설치된 각 스킬 폴더의 원문에 그대로 있습니다.
- 설치 목록은 이 패키지에 없습니다. 서버가 주문번호를 보고 **산 만큼만** 알려 줍니다.
- 저희가 만든 스킬은 결제한 분께만 드리는 묶음이라, 서버가 15분짜리 주소를 주면 그때 받아 `~/.claude/skills` 에 풉니다.
- 홈 폴더의 설정은 건드리지 않습니다. 쪽지는 **지금 폴더**의 `CLAUDE.md` 뒤에 덧붙입니다.
